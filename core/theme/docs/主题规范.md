# 主题4（docs）

这份规范随主题包走。目录：`core/theme/docs/`。后台名称「主题4」。

## 这个主题是什么

首页是文档简介，不是某一个接口。点进接口才进入文档页。文档页按管理端「接口文档」还原。没有编辑按钮。多一个在线测试。友情链接、赞助、关于、全部接口、文章、贡献者跟主题一。

- 电脑端：左侧目录（搜索、分类、文件夹图标、方法色）+ 右侧文档。标签色、参数表、JSON 高亮跟后台一致。
- 手机端：点「接口目录」从**左边**滑出。顶栏菜单跟主题一，从右边滑出。
- 不要底部栏。
- 导航跟主题一：首页、全部接口、文章、贡献者、友情链接、赞助、关于（由 `navItems()` 注入；可用主题设置 `nav_show_*` 逐项隐藏入口，默认全开；不影响 SEO）。
- 在线测试：已登录且账户有 KEY 会自动填入，页面不直接输出 KEY。
- 顶部栏和登录、注册、找回密码、绑定页照主题一，文件在本包里。
- 没有已发布公告就不显示公告条和弹窗。有公告时，弹窗按主题一的尺寸，打开前挂到页面最外层，关闭按钮必须能点到。
