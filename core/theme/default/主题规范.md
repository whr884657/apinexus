## 一、这是谁

黑白灰极客体。class 不使用 `st-*` / `th3-*` / `th5-*`。  
粒子为灰点，由壳 `shell.js` + `--particle-color` 画，页面脚本禁止再画绿色粒子（E87）。  
资源只出 `core/theme/default/assets/`。禁止引用其它主题文件。

---

## 二、认证页

- 左侧深色网格展区保留彩色小人；右侧玻璃表单卡。入场由本包 `assets/vendor/anime.min.js` + `auth.js` 驱动，尊重 `prefers-reduced-motion`。
- 身份分段类名：`vs-role-segment`。仅一种身份时整条不渲染。
- 字段不单独占一行 label，说明写在 `placeholder` + `aria-label`。
- 登录顺序：账号 → 密码 → 人机验证 →「验证码登录 / 忘记密码」→ 提交。见《登录认证表单顺序规范》。

## 三、顶栏登录入口

| 状态 | 电脑 | 手机 |
|------|------|------|
| 未登录 | **一个**按钮，文案固定 `登录 / 注册`，只链 `/user/login` | 汉堡侧栏同一文案、同一链接 |
| 已登录 | 「用户中心」→ `/user/index` | 侧栏用户中心 |

禁止拆成「登录」「注册」两个按钮。禁止顶栏直链注册页。文案跟注入的 `$authLabel`。禁止用 `hidden md:inline-flex` 控显隐（`.hidden` 曾把电脑端入口藏掉）。

## 四、首页与详情

- 首页标题只出站点名，禁止「首页 - 站点名」。
- **接口目录卡片（首页 / 全部接口 / 贡献者个人主页）不展示调用路径**（不带域名的 path / endpoint 文案）。详情页「接口信息」地址框、在线测试预览不受影响。
- 详情 info-grid 顺序：Method → 分类 → Calls → KEY → 计费 → QPM → 作者 → 提交时间。作者只读 `FrontendApi` 已填字段。
- 详细文档半折叠预览（首段 + 渐隐，点击展开）。快速上手语言 Tab 图标必须跟着鉴权切换重绘，不得丢 `icon_gray` / `icon_color`（E137）。
- 标题行只有「复制 Markdown」（`#detailCopyMdBtn`）。禁止问问豆包跳转。
- 在线测试：`#pgCopyBtn` 只在文本/JSON/HTML 出现；JSON/OpenAPI 约 16 行、返回示例约 20 行上限内滚动；表格不限高（E315）。
- OpenAPI 只读服务端 `openapi_json`，禁止主题手写拼装（E314）。
- 未配置简介时，贡献者页与个人主页可用一言（`hitokoto-bio.js`）。**只有主题一接一言。**
- **贡献者个人主页接口列表：** 默认「随机」须真正打乱（PHP `shuffle` + `profile-search.js` 首屏 `apply`）；禁止只标 active 却按 `id` 倒序原样展示。接口多时须底部分页（对齐全部接口页序号分页，每页约 20 条）。

## 五、首页公告（本主题是间距抄本）

没有已发布公告时，不输出滚动条、弹窗和脚本。禁止写死「欢迎使用…已上线」（E340）。

弹窗打开前挂到 `document.body`，`z-index: 500`。CSS 抄本：`assets/css/pages/index.css` 的 `.home-announcement-modal*`；行为抄本：`assets/js/pages/home-announcement.js`。

| 场景 | 规定 |
|------|------|
| 桌面遮罩 | `position: fixed; inset: 0`，根层无 padding |
| 桌面卡片宽 | `min(760px, calc(100% - 24px))` |
| 桌面卡片高 | `max-height: calc(85vh - 32px)`，并写 `85dvh` |
| 正文闸门 | `max-height: min(55vh, calc(100vh - 11rem))`，区内滚动 |
| 手机（≤768px） | 宽 `calc(100% - 16px)`；高 `calc(100svh - 4rem)`；`translateY(-3%)` |
| 手机正文覆盖 | **只**写 flex / `min-height: 0` / `overflow: auto`。**禁止** `max-height: none`（E318） |

主题二若要同一套留白，以**本节实际数值**为准，不得在主题二规范里另写一套间距。主题二只换配色。

## 六、用户中心

- 有调色盘。`theme-picker.js` 写 `--page-bg`，并派生 `--vs-uc-hero-bg`。禁止英雄条写死纯绿/纯蓝。
- 可选色只有系统 24 色预设，禁止 `<input type="color">`。
- 控制台时段问候只在主题一：按小时问候；深夜提醒休息。
- 签到细条跟英雄条变量。数据走 `FrontendUser::checkinBanner()`。
