## 一、这是谁

视觉只以**本包首页**为基准：暖纸底 `--bg/#FBFAF7`、强调色 `--accent/#FF4D2D`、字阶 `font-display`。  
其它公开页、认证页按首页的色彩、圆角、按钮、卡片自己设计。禁止把 default / slate 的 `pages/*`、`st-*`、整包 CSS 改个名搬过来（E323）。

资源只出 `core/theme/three/assets/`。Markdown 用核心 `Markdown::render`，不要绑主题二的短码类名。预览图 `preview.png` 禁止删除。

数据仍走 `Frontend*`。详情必须接 playground / 快速上手 / 反馈约定 id。OpenAPI 只读 `openapi_json`（E314）。

## 二、圆角（全主题三控件）

| 令牌 | 值 | 用途 |
|------|----|------|
| `--th3-radius` | `10px` | 输入框、主按钮、复制钮、地址条、代码块外壳、Tab pill、本地验证码框 |
| `--th3-radius-inner` | `6px` | 控件里的小图（验证码图） |
| `--th3-auth-radius` | `var(--th3-radius)` | 认证页别名，禁止再写第二套数字 |

定义在 `assets/theme.css` 与 `assets/auth.css` 的 `:root`。改角度只改变量。

必须用这个角的：认证输入与提交钮；详情 `.th3-endpoint`、参数框、`#pgSendBtn`、`.th3-copy`、`.th3-pill`、`.th3-code`、`.th3-pg-response`。

允许例外：装饰光晕可以是圆；大卡片外壳可以略大（约 16～18px），但**卡片里面的输入和按钮**仍是 10px。极验内部把手禁止主题去改。

禁止：输入 10px、按钮却是胶囊 `999px`；把主题一或主题二的圆角体系拷进来；只改认证页、详情仍用旧角。

## 三、详情与公开页

- 复制钮用紧凑 `.th3-copy`。禁止套首页大号 `.btn-ghost`（E324）。
- Response 用 `.th3-pg-response` 自有外框，可滚动。不是照搬 default 的类名。
- OpenAPI 须美化缩进再展示。核心若给的是紧凑 JSON，**在主题三渲染前**再 pretty，不要强迫其它主题一起改。
- `#pgCopyBtn` 仅非媒体可见。JSON/OpenAPI 约 16 行、返回示例约 20 行（E315）。
- 公开页电脑端限宽居中、两侧留白：文章约 900、关于约 800、友链约 960、贡献者约 1200（E325）。用 `.th3-page__inner--*` 或在 `tw-compat` 里声明用到的 `max-w-*`。
- **`tw-compat` 间距类必须齐（E364）：** 页面写了 `mb-5` / `mb-6` / `sm:mb-8` 等，compat 里没有就会「间隙消失、块贴块」。改首页/详情 class 前先扫 `tw-compat.css`；关键间距优先在主题 CSS 写语义 margin（如 `.th3-endpoint`），勿只赌工具类。
- **请求参数表（E372）：** `#paramsTableMode` 须 `table-layout:fixed` + 说明/示例 `word-break`；`.th3-table-wrap` 限宽 `overflow-x:auto`。禁止说明过长把详情面板横向撑开（对齐主题1参数表行为）。
- **Markdown 正文图：** 须 `max-width:100%; height:auto`，禁止拉成正方形（核心 `markdown-render.css` + `.th3-md img`）。
- 文章封面四态须生效。外链图走 `data-ext-icon`。
- 首页禁止在线演示板块。调试只留详情「在线测试」。下线后的 `theme-playground.js` 和只服务首页 demo 的 CSS 必须删净，并写入 `install/obsolete-files.json`（E307 / P09）。
- 在线测试需要 KEY 时，已登录且账户有 KEY 则自动填入输入框。提示文案与主题一相同。走 `POST core/front/playground-key.php`，页面不直接输出 KEY（E253）。
- API 市场：分类标签换行小胶囊；搜索框 `th3-api-search`，输入即筛，禁止搜索框后面再放一个按钮。
- 卡片保留描述，底部显示调用量，不要在卡片底显示 GET/POST。

## 四、首页公告

没有已发布公告，或关掉 `show_home_announce`：不输出滚动条和弹窗（E340）。

- class：`th3-announce-*`。条 `fixed` 在顶栏下方，留约 0.5rem，禁止和顶栏粘成一条。
- 配色走本主题红/纸色，不抄青绿，也不抄黑白灰。
- 长公告**不得整卡贴顶**。正文在卡片内滚动。不得用「视觉独立」当借口写成贴顶（见 E318 的坑，本主题同样禁止 `max-height: none` 把闸门拆掉）。
- 弹窗打开前挂 `document.body`，不能困在带 `z-index` 的包壳里。

## 五、顶栏、昼夜、页脚

- 下拉菜单用实心 `var(--card)`。汉堡必须看得见（品牌区 `min-width: 0`）。顶栏高度：手机 3.75rem，电脑 4rem。
- `html.dark` 同步 `--bg` / `--fg` 与壳层 `--vs-*`。首页推荐卡 `.price-card.featured` 用反色；暗色铺底时选择器必须 `:not(.featured)`，推荐卡单独浅底深字（E321）。
- **首页标题下方描述：** 主题设置 `hero_lead`（多行）。空白则用内置默认介绍。首页用 `nl2br(vs_e(...))` 输出，禁止裸输出。
- **首页充值展示卡（强制）：** 三张卡完全由主题设置 `home_price_{1-3}_*` 配置（名称/价格/积分/描述/卖点 + `home_price_featured`），**禁止**再读 `PayConfig::packages()`。与系统充值套餐互不影响；按钮仍链到 `/user/recharge`。须同步写进 `lib/admin-settings.php`。
- **首页区块 eyebrow：** 禁止在「海量接口…」「不仅是聚合…」「积分充值…」等大标题上方再写 `/ API 市场`、`/ 核心能力`、`/ 积分充值` 一类斜杠标签。
- **主题设置面板：** 本主题有自定义后台面板 `lib/admin-settings.php`。`theme.json` 里新增的键，**必须同时**写进这个面板的分组里，否则后台看不到（只进 schema 不够）。
- 页脚社交最多 3 个，键名 `footer_social_{1-3}_*`。须接自定义栏、备案、运行时间脚本。禁止写死友链列表，禁止虚假 uptime。
- **系统页脚二维码：** 页脚必须调用 `vs_render_footer_qrs()`。图源是系统设置「展示与自定义」里的页脚二维码，不是社交槽里的微信二维码。主题设置键 `show_footer_qr`（默认开）。
- **页脚布局（强制）：** 站名/描述（或友链）在上；**社交图标与系统页脚二维码同一底行**（左社交、右二维码，`.th3-footer__dock`）。禁止把二维码单独插在描述与社交之间，造成右上/右下大片空白。
- **页脚友情链接：** 主题设置 `show_footer_friend_links`（默认关，后台文案「底部友情链接（替换站名与描述）」）。**开启**后，页脚左侧的站点名称与站点描述整块换成友情链接（数据走异步 `core/front/links.php` / `data-vs-footer-links`，数量键 `footer_friend_links_display`）；**关闭**后恢复站名与描述。二维码仍在底行靠右。
- 二维码气泡：默认居中；**第一个**社交槽 `left: 0`，禁止 `translateX(-50%)` 在手机贴左时溢出；最后一个且不是唯一时 `right: 0`（E320）。
- **详情 Tab：** 切换 Tab **禁止** `history.replaceState` / `location.hash` 往地址栏写 `#params` / `#response` 等碎片（E358 / **E368**）；首次进入可读遗留 hash 并**立刻清掉**。全站遵守《开发规范与功能优化》§2.4 / 防呆 P16。
- 控制台品牌脚本用 `th3_emit_console_brand_script()` 输出根相对路径。禁止页脚写死 `https://域名`。
