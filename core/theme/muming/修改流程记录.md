## 2026-09-23 · 新增全局看板娘助手：二次元形象 · 互动气泡 · 随机推荐接口

### 背景

平台需要一个更有亲和力的常驻形象：二次元看板娘固定于页面左下角，动作丰富、互动多，可随机推荐可用接口，并支持管理后台一键关闭。

### 本轮改动

| 路径 | 变更 |
|------|------|
| `theme.json` | 新增 `mascot_enabled`（checkbox，默认 true），settings 数 50 |
| `lib/admin-settings.php` | 「功能开关」区新增 `$renderCheckbox('mascot_enabled');`（L118） |
| `layout/footer.php` | 页脚末尾新增看板娘容器，`ThemeManager::themeSettingBool('mascot_enabled', true)` 条件渲染；末尾引入 `assets/js/mascot.js`（defer，带 VS_VERSION 缓存号） |
| `assets/theme.css` | 末尾新增「K. 看板娘助手」样式段：fixed 左下（左 22 / 下 24，z-index 160，避开返回顶部 950 与头部菜单 190–203）、气泡带三角箭头、浮动/弹跳动画、桌面 150px / 移动 112px、`prefers-reduced-motion` 降级、`.th5-mascot__bubble-link[hidden]{display:none}` 显隐修复 |
| `assets/js/mascot.js` | 新增交互脚本：开场问候（约 1.8s）、45–90s 随机小提示、点击形象随机反应 + happy 表情（2.6s 复原）、随机推荐接口（过滤 disabled/maintenance；数据源 `window.TH5_CATALOG_APIS` / `TH5:catalog` 事件 / `VS.fetchFrontCatalog` 兜底）、推荐气泡 8s 带「去看看」跳详情、点「×」会话内隐藏（sessionStorage） |
| `assets/img/mascot/` | 新增 2 张 Q 版蓝发女仆看板娘素材（`mascot-idle.png` 434×885 / `mascot-happy.png` 469×872，白底抠透明） |

## 2026-09-23 · 接口分类去重：桌面端仅左侧目录 / 手机端仅上方横向条

### 背景

首页与全部接口页同时渲染两套「接口分类」：列表上方横向滚动条（`.th5-catbar`）与列表左侧目录（`.th5-cat-q`），桌面端与手机端都会重复出现。

### 本轮改动

| 路径 | 变更 |
|------|------|
| `assets/theme.css` | `.th5-catbar` 默认 `display:none`（桌面端隐藏，仅保留左侧目录）；`@media (max-width: 767px)` 下 `.th5-catbar` 恢复 `display:flex`（列表上方横向条）、`.th5-cat-q` 隐藏 |

### 自测建议

1. 查看双端“接口分类模块”是否重复出现，当前手机端在API列表板块顶部，桌面端则在API列表左侧  
2. 请测试文章/接口/贡献者/友链/赞助/关于等页面看板娘展示是否出现异常：大小不一，位置偏差（因头部消息弹窗会导致看板娘在视窗右上或最右侧时因需合理展示内容，会适当自动向左下或向左移动到合适位置，以便展示文字内容）

## 2026-09-22 · 详情页 / 顶距 / 页脚二维码 / 首页步骤与按钮（theme 仍 0.1.7）

### 本轮改动

| 路径 | 变更 |
|------|------|
| `pages/detail.php` | 去掉端点 `$`；复制钮改 `th5-copy-btn`（参数/返回/快速上手/在线测试） |

## 2026-09-22 · 对齐 13.26.45 + 前台壳层修复（theme 0.1.7）

### 背景

1. 主题开发者换新包后，系统侧曾做的聚合登录 / 充值对齐未留在包内，需重做。  
2. 新包上线后前台出现：顶栏滚动被顶走、公告贴顶栏、手机页脚三列竖排过长、侧栏遮罩盖顶栏、公告横幅盖住侧栏、验证码按钮胶囊圆角与输入框不一致。

### 本轮改动

| 路径 | 变更 |
|------|------|
| `user/auth/login.php` | `$oauthButtons` 循环渲染（含聚合 `agg`） |
| `user/pages/account.php` | `$oauthButtons`；agg 解绑带 `item_id` |
| `assets/js/account.js` | 解绑后按 `item_id` 重建 `provider=agg&id=…&intent=bind` |
| `user/pages/recharge.php` | 预计到账 → `vs-notice--tip` + `#rechargeCustomHintPts` |
| `assets/js/user-recharge.js` | `resolvePayQrSrc` + `qr_kind`；hint 只改积分数字 |
| `assets/shell/user-shell.css` | `#rechargeCustomOverlay` 脚栏同高（E347） |
| `主题规范.md` | 正名「慕名 / muming」；核心对接表 + mermaid 流程图 |
| `theme.json` | **0.1.6 → 0.1.7** |
| `assets/theme.css` | 顶栏强制 `fixed`；遮罩自顶栏下方起；公告 z-index 170；公告与顶栏间隙；有公告时 hero 顶距；手机页脚品牌通栏 + 导航\|资源左右 + 快速开始单独一行 |
| `layout/header.php` | 去掉手机菜单无用的 `z-50`（改由 CSS 叠层） |
| `assets/auth.css` | `.th5-auth__code-btn` 圆角 `999px` → `14px`（与输入框一致） |
| `修改流程记录.md` | **新建**（本文） |

### 叠层约定（维护勿乱改）

| 层 | z-index | 说明 |
|----|---------|------|
| 顶栏 `.th5-header` | 200 | `position: fixed` |
| 顶栏内栏 / 菜单钮 | 202–203 | 高于遮罩 |
| 手机菜单面板 | 195 | 顶栏下方展开 |
| 菜单遮罩 `.menu-backdrop` | 190 | **top 从顶栏高度起**，禁止 `inset:0` 盖顶栏 |
| 首页公告横幅 | 170 | 低于侧栏/遮罩，打开菜单时横幅在罩下 |

### 自测建议

1. 桌面 / 手机：页面上下滚动，顶栏始终吸顶不滚走  
2. 有公告：横幅与顶栏之间有可见缝隙；点开手机菜单时，灰罩不盖顶栏，横幅不浮在菜单之上  
3. 手机页脚：品牌一行；「导航」「资源」左右并列；「快速开始」单独一行  
4. 登录系页面：「获取验证码」圆角约 14px  
5. 聚合登录：登录/账号页可用  

### 未改
