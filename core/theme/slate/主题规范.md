## 一、这是谁

浅色青绿平台。认证页双栏（左品牌 / 右表单），结构可参考主题一的「左介绍右表单」，**皮肤必须是青绿，禁止整页换成主题一的黑白灰**。  
资源只出 `core/theme/slate/assets/`。禁止回退加载 default 视图。

正文 Markdown 走 `SlateMarkdown::render()`，短码 `:::stcallout` / `:::ststeps` / `@[api](id)` / `==高亮==` 只属于本主题。不要把这套短码类名安到其它主题上冒充。

## 二、详情与列表

- 详情上半区是接口身份和信息网格；下半区是横向标签，电脑和手机都可横滑。禁止照搬主题一自上而下堆满参数/文档/测试。
- 能力要齐：参数表 / JSON / OpenAPI、返回示例、文档、快速上手、在线测试、反馈。标题行「复制 Markdown」（`#detailCopyMdBtn`）。禁止问问豆包。
- OpenAPI 只读 `openapi_json`（E314）。`#pgCopyBtn` 规则与代码区行数上限与全站约定一致（E315）：仅文本可复制；JSON/OpenAPI 约 16 行、返回示例约 20 行。
- 免责声明在 Tab **下方常显**，禁止单独做一个 Tab，禁止「推荐接口」。
- 接口地址行只展示方法 + 主机/路径。禁止地址旁「复制」「打开」。标题上方禁止再堆方法/免费/KEY 芯片（禁用、维护可留）。
- 卡片上方法与状态必须同一行。禁止绝对定位把状态挤到第二行。
- 全部接口页禁止「重置」按钮。搜索用 `st-search`。
- 首页禁止「在线调试」和 Hero「全部接口」一类多余按钮。列表底部一条全宽「全部接口」进 `/apis`。不要再暴露 `show_home_playground`。

## 三、首页公告

没有已发布公告，或主题设置关掉 `show_home_announce`：不输出滚动条和弹窗（E340）。禁止写死欢迎文案。

- class：`st-announce-*`。脚本 `home-announcement.js`。
- **间距与运行规则以《主题一规范》第五节的数值为抄本**（桌面宽、55vh 闸门、手机禁止 `max-height: none`）。本主题不另定一套间距（E316 / E318）。
- **配色只属于本主题：** `--st-accent` 主按钮白字，次按钮白底深字。禁止白底白字。
- 弹窗挂 `document.body` 后，token 必须写在 `.st-announce-modal` 上，或用 `stSyncAnnounceModalTokens` / `st-tint` 同步。变量不能只挂在 `.st-root`，否则挂到 body 后丢色。
- `z-index: 500`。公告条与顶栏之间要有间隙。弹窗不透明白底。禁止页面底部中间「返回顶部」。

## 四、页脚与友链

- 法律信息区的断行规则照主题一：手机版权、ICP、公安各成一行；电脑版权在左、备案在右。禁止把它们塞进同一个 `.st-foot__copy` 横排挤在一起（E319）。三栏自定义用 `vs_render_footer_custom_bar()`，本主题只换颜色。
- 友链页只在**页面底部**留一处「申请友链」。禁止顶部再叠一个。

---

## 五、认证与导航

- `.st-auth__title` 必须静止。禁止字距或透明度无限脉冲（E286）。
- 身份分段类名：`st-role-segment`。
- 导航：`nav_expand_mode` = `top_drawer`（顶栏抽屉）或 `fab_popup`（右下角 FAB）。圆形按钮内三横线须几何居中。
- 贡献者个人主页用 `st-profile-*`。搜索用大号 `st-search`，禁止窄小 `st-input`。
- 依赖 `VS.postForm` 的页面脚本必须排在系统 `common.js` 之后。禁止在页面中部抢先 defer，禁止整页提交出裸 JSON（E292）。

## 六、用户中心

- **没有调色盘。** 英雄条固定青绿渐变（`--st-uc-*`）。前台 `.st-root` 仍可用 `st-tint`。
- 签到细条走青绿，不跟主题一的调色盘变量。
- 控制台文案固定「欢迎回来」，不要抄主题一的按时段问候。
