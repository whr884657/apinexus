# ApiNexus 10.4.0

## 本版要点

- **日志刷新**：后台「日志查询」刷新会清掉列表缓存并回到最新一页，能看到当前库中最新日志
- **注册赠送积分**：系统设置开关与赠送数量；邮箱注册成功后自动入账
- **每日签到**：系统设置开关与随机积分区间；默认主题用户中心首页横幅提醒；签到后横幅消失；流水记「每日签到」

## 升级注意

- **有数据库变更**：请走系统升级以执行 `install/migrations/10.4.0.sql`（`checkin` 表、配置项、`orders.kind` 注释）
- 注册赠送 / 签到默认关闭，需在「系统设置」手动开启
- 签到横幅仅默认主题用户中心控制台展示；主题二本版不接横幅
