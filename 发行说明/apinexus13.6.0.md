# ApiNexus 13.6.0

**发布日期：** 2026-07-29

## 变更摘要

- **行为验证（极验）：** 系统级接入第三代 / 第四代；SDK 内置于 `core/captcha/`
- **系统设置：** 分场景开关管理员登录/忘记密码、用户登录/注册/忘记密码；可单开或多开
- **校验时机：** 登录在提交时校验；注册与忘记密码在发送邮箱验证码时校验
- **安全：** 验证密钥仅存服务端；前端仅公开 ID 与初始化参数
