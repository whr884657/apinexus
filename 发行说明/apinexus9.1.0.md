# ApiNexus 9.1.0 发行说明

**发布日期：** 2026-07-25  
**数据库变更：** 无

## 本版摘要

- **令牌管理 / 接口反馈（手机）：** 隐藏「全部状态 / 全部」等筛选下拉，仅保留搜索，避免小屏挤占标题行
- **接口文档：** 请求示例与响应 JSON 代码块改为白底浅色；本地 `VsSyntax` 语法高亮（关键词/字符串/数字等着色，类似 IDE）
- **Markdown 文档 Tab：** 挂载统一渲染样式，标题/列表/表格/引用/代码更好适配 Markdown 语法
- **规范：** 补 E100 / E101 与相关专项条款

## 升级注意

覆盖更新后请强制刷新后台 CSS/JS（Ctrl+F5）。无需执行数据库结构更新。
