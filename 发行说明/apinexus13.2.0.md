# ApiNexus 13.2.0

**发布日期：** 2026-07-28

## 变更摘要

- **IP 归属地：** 系统设置支持「系统内置 / 自定义接口」双模式；内置开箱即用，无需填写第三方 URL；界面与源码不暴露上游厂商名称
- **市区飞线：** 按调用方归属地的地级市/州精确出发（如云南省曲靖市→曲靖），不再盲目落到省会；剥离电信/移动等运营商尾缀
- **流星雨：** 飞线改为亮圆头 + 长尾迹，按调用量绿/黄/红着色，从出发城市坠入本站枢纽
- **版本规范：** 明确补丁 Z / 次版本 Y / 主版本 X 三段式；无库破坏、无破坏性契约时禁止跳升主版本
