# ApiNexus 9.0.0 发行说明

**版本：** 9.0.0  
**日期：** 2026-07-25  
**数据库：** **有结构变更**（新增 `feedback` 表）

## 变更摘要

- **令牌管理**：电脑白底表格 + 手机卡片；标题行搜索/状态筛选；复制 Key、重置、紧急禁用/启用、删除
- **接口文档**：结束占位；左侧按分类浏览接口，右侧查看参数、请求/响应示例与文档
- **接口反馈**：结束占位；表格/卡片双端列表、详情弹层标记已处理；需执行数据库结构更新创建 `feedback` 表

**升级说明：**

1. 覆盖更新源码  
2. 进入「系统管理 → 系统升级」执行 **数据库结构更新**（应用 `9.0.0` 迁移）  
3. 强刷后台 CSS/JS 缓存
