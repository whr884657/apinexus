# ApiNexus 10.0.0 发行说明

**发布日期：** 2026-07-25  
**数据库变更：** 是（新增 `comment` 文章评论表）

## 本版摘要

- 公告管理、文章管理：参照后台列表规范，改为桌面表格 + 手机卡片双 DOM，支持搜索与底栏分页
- 评论管理：上线完整后台（回复 / 置顶 / 审核 / 删除）；评论须填写邮箱；数字 QQ 邮箱自动取 QQ 头像，否则本地随机头像
- 合作伙伴表单增加简介；友链与合作伙伴操作按钮改为规范小按钮样式

## 升级注意

1. 覆盖代码后，请到「系统管理 → 系统升级」执行数据库结构更新。
2. 强制刷新后台 CSS/JS。
3. 前台评论展示可后续接入 `FrontendComment`。
