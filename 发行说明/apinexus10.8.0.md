# ApiNexus 10.8.0

## 本版要点

- **首次全盘复查**：按「安全 → 防打爆 → 功能」优先级，以流程记录 3.9.0～10.7.0 为索引，分波次覆盖业务入口与关联调用链
- **支付**：充值异步回调履约加固（金额比对已在 10.8.1 按码支付同额并发场景撤销，见现行《支付开发规范》§2.6）
- **在线更新**：ZIP 禁止危险路径解压（Zip Slip）；更新 API 同源/CSRF/限流；异常不回传内部信息
- **网关 / 中继**：收费接口不可经 Playground 中继白嫖；出站重定向逐跳公网校验；代理 `targeturl` 禁内网；密钥错误仍计 IP QPM
- **日志 / 前台**：调用日志密钥脱敏；前台公开列表硬顶 500；分类标签请求内缓存；`countForTheme` 改 COUNT
- **规范**：§2.25 全盘复查规范 + E115

## 升级注意

- 无数据库结构变更
- 强刷后台静态资源（若浏览器缓存了更新页 / 日志页脚本）
- 旧主题若仍走中继测收费接口，将收到 402，请改浏览器直连公开调用地址
