# ApiNexus 9.2.0 发行说明

**发布日期：** 2026-07-25  
**数据库变更：** 有（请执行系统升级 → 数据库结构更新）

## 本版摘要

- 默认主题详情页新增「接口反馈」：登录用户可直接提交；未登录会提示并跳转登录
- 管理员标记已处理时可填写回复（也可不写），并邮件通知用户
- 系统设置中可开关「接口反馈处理结果」邮件通知
- 提交需登录，并做同源 CSRF、字数与防刷校验；登录后可回到详情页

## 升级注意

1. 覆盖代码后执行 **系统升级 → 数据库结构更新**
2. 强制刷新前台/后台 CSS、JS
3. 确认邮箱已配置，并按需打开反馈处理通知开关
