# ApiNexus 9.2.0 发行说明

**发布日期：** 2026-07-25  
**数据库变更：** 有（配置项 `mail_notify_feedback` 等，请执行系统升级 → 数据库结构更新）

## 本版摘要

- **默认主题详情页**新增「接口反馈」：登录用户填写问题后直接提交；未登录点击提交会提示「请登录后提交反馈问题」并跳转登录（登录后可回详情页）
- **管理员后台**：标记已处理时可填写回复（也可空回复）；首次处理完成会邮件通知该用户
- **系统设置 → 邮箱**：新增开关「接口反馈标记已处理时，通知提交用户」
- **安全**：CSRF + 同源、须登录、5～2000 字、同接口 60 秒防刷、回跳白名单

## 升级注意

1. 覆盖代码后执行 **系统升级 → 数据库结构更新**
2. 强制刷新前台/后台 CSS、JS
3. 确认邮箱总开关与 SMTP 已配置，并按需打开 `mail_notify_feedback`
