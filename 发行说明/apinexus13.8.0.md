# ApiNexus 13.8.0

**发布日期：** 2026-07-29

## 变更摘要

- **文档徽章：** 管理员「接口文档」页元信息标签（本地/代理、KEY、收费、QPM 等）恢复与接口列表同色系，不再全灰
- **用户 API 同权：** 与管理员绑定的开发者在 API 管理列表可见本地/代理标签；投稿本地能力保持不变
- **用户 AI 文档：** 开发者投稿表单可 AI 生成详细文档与分片代码示例（不要求绑定管理员）；协议与后台一致
- **控制台：** 用户中心控制台展示积分、接口/令牌统计、快捷入口；default 与 slate 主题分别配色

## 升级注意

无数据库结构变更。升级后请刷新浏览器缓存（CSS/JS）。若需使用 AI，请在系统设置启用 AI 对接。
