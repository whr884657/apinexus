# ApiNexus 9.2.2 发行说明

**发布日期：** 2026-07-25  
**数据库变更：** 有（新增配置项，请执行系统升级 → 数据库结构更新）

## 本版摘要

- 修复后台「查看 / 标记已处理」无反应：弹窗正确打开，操作结果正确提示
- 用户提交反馈后，可向管理员发送邮件通知（系统设置可开关）
- 处理完成后通知用户的邮件逻辑保持可用

## 升级注意

1. 覆盖代码后执行 **系统升级 → 数据库结构更新**
2. 强制刷新后台 JS（`api-feedback.js`）
3. 确认邮箱 SMTP 已配置；在系统设置中打开：
   - 「有新的接口反馈时，通知管理员」
   - 「接口反馈标记已处理时，通知提交用户」
4. 管理员账号与用户账号需填写有效邮箱
