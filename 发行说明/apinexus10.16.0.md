# ApiNexus 10.16.0

**发布日期：** 2026-07-27  
**数据库变更：** 否

## 本版摘要

控制台指标按设置间隔刷新；可配置 IP 归属地 API；默认主题友链开关/免责声明/随机排序；前台 Redis 缓存扩充。

## 主要变更

| 模块 | 说明 |
|------|------|
| 控制台 | live 含累计调用与系统概览；缓存 TTL=刷新间隔；软刷≈6×间隔 |
| IP 归属地 | 设置页配置 URL/认证/额外参数/JSON 路径；写入 `apilog.iploc` |
| 站点扩展 | 免责声明（详情页快速上手后）；页脚友链开关（默认开） |
| 顶栏 | 移除重复「退出」（侧栏保留） |
| Redis | 接口/分类/友链/文章/公告/其他/IP 缓存纳入监控 |
| 默认主题 | 全部接口 shuffle；首页常显「查看全部接口」 |
