# ApiNexus 10.5.0

## 本版要点

- **积分搜索**：用户名 / 邮箱 / 类型文案（注册赠送、签到等）可搜；EXISTS 避免 JOIN 不一致导致空结果
- **类型配色**：积分变动标签按种类分色
- **接口 QPM**：`api.qpm`，0=不限制；无需/可选密钥按 IP，必填密钥按 IP+密钥；本地与代理共用守卫
- **详情页**：默认主题 info-grid 增加 QPM（N/MIN）与作者（头像+名 → 个人主页）

## 升级注意

- **有数据库变更**：请走系统升级以执行 `install/migrations/10.5.0.sql`（`api.qpm`）
- 新装已含 `qpm` 列时 Migrator 会跳过标记
- 强刷后台 / 前台缓存后验证积分搜索与接口编辑、详情展示
