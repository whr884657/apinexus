# ApiNexus 10.6.1

## 本版要点

- **日志时区**：PHP 固定 `Asia/Shanghai`，数据库连接后 `SET time_zone = '+08:00'`，调用日志 / 订单等 `NOW()` 与服务器本地钟一致（修复显示成 UTC 的 20:xx）
- **状态码说明**：调用日志详情展示 `401 / 402 / 403 / 429 / 302` 等可读含义，不再只有「失败」+ 数字
- **Redis UI**：业务缓存项改回中文名称；连接状态格仅保留运行时长与版本（连接状态仍在右上角徽章）

## 升级注意

- 无数据库结构变更
- **已写入的旧日志时间不会自动改写**；升级后新产生的日志时间为东八区
- 强刷后台静态资源后查看日志详情与 Redis 管理页
