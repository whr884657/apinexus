# 本地接口 · 调用统计代码怎么用

面向站长 / 接口作者。把统计代码贴到**本地接口 PHP 文件最上面**（`<?php` 之后、业务代码之前）。

安全与 JSONP、响应勿泄露等：**请先读** [接口开发安全须知.md](接口开发安全须知.md)。

---

## 唯一写法（须填接口 ID）

用 `dirname` 定位站点根目录的 `core/bootstrap.php`，并在 `ApiStats::hit(接口ID)` 中填入后台该接口的数字 ID：

| 脚本位置 | `dirname` 写法 |
|----------|----------------|
| `api/xxx.php`（api 根下） | `dirname(__DIR__)` |
| `api/foo/xxx.php`（多一层） | `dirname(__DIR__, 2)` |
| `api/a/b/xxx.php`（再深一层） | `dirname(__DIR__, 3)` |

完整示例（脚本在 `api/foo/xxx.php`，接口 ID 为 `14`）：

```php
<?php
require_once dirname(__DIR__, 2) . '/core/bootstrap.php';
ApiStats::hit(14);
```

说明：

1. **接口 ID 必填。** 在管理员后台「接口管理」列表可见；不填或填 `0` **不会记账**。
2. 不再按脚本路径自动猜接口；路径与 `endpoint` 不一致时也不会误记到别的接口。
3. 兼容 PHP 7.4～8.2。
4. 后台「调用地址」仍请写成与脚本一致的路径，如 `/api/foo/xxx.php`。

## 本地脚本再请求外网时（出站 UA / Referer）

后台可为**本地接口**配置出站 User-Agent / Referer（与代理共用同一套选项）。脚本在 `hit` 之后这样用：

```php
ApiStats::hit(14);
$ch = curl_init('https://example.com/api');
curl_setopt($ch, CURLOPT_HTTPHEADER, ApiStats::outboundHeaders());
curl_setopt($ch, CURLOPT_USERAGENT, ApiStats::outboundUa());
// 需要单独 Referer 时：ApiStats::outboundReferer()（空串表示不发送）
```

也可写 `ApiStats::outboundHeaders(14)`，显式指定接口 ID。

> 规则：`dirname` 第二个参数 = 从当前文件所在目录走到站点根要上跳的层数。

---

## 代理接口要不要贴？

**不要。** 对外地址是 `/apis/短码` 的代理接口，由系统网关自动统计。

---

## 常见问题

| 现象 | 处理 |
|------|------|
| 调用了但次数不涨 | 检查是否写了正确的接口 ID；先做结构更新；接口已通过审核且状态为「正常」 |
| 返回「该接口已经被禁用」 | 后台将该接口状态改为「正常」 |
| 返回「该接口维护中」 | 后台结束维护，改回「正常」 |
| 返回「密钥错误」/「请提供调用密钥」 | 检查是否必填密钥；使用用户中心「令牌管理」中启用中的 `SK-…` 密钥 |
| 返回「密钥已禁用」 | 在令牌管理中重新启用该密钥 |
| 找不到 bootstrap | 核对本节目录层数表，改对 `dirname` 层数 |
