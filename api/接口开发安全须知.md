# 本地接口 · 开发与安全须知

面向站长 / 接口作者。把业务 PHP 放在站点 `api/`（或子目录）时，**除调用统计外**，请按本文自检。  
演示包 `api/demo/` 仅供联调参考，**不代表**可直接用于生产的安全写法。

关联：[统计代码使用说明.md](统计代码使用说明.md)

---

## 一、必做：调用统计

每个本地接口文件顶部须：

```php
require_once dirname(__DIR__) . '/core/bootstrap.php'; // 按目录深度改 dirname 层数
ApiStats::hit(接口数字ID);
```

细则见《统计代码使用说明》。**代理接口不走本文件**——公开地址是 `/apis/{短码}`，由平台网关记账。

## 二、JSONP / callback（高危，务必看）

### 风险

若把用户传入的 `callback` / `jsonp` **未校验**就：

- 拼进上游 URL，或  
- 直接 `echo $callback . '(' . $json . ');'`

攻击者可注入 `alert(1)`、`(function(){…})//` 等，造成**同源反射型 XSS**。浏览器里若再配合页面脚本可读的敏感数据（例如误存的账号密码），危害更大。

### 正确做法（三选一，推荐 1）

1. **不做 JSONP**：只返回 `Content-Type: application/json`，忽略 `callback` 参数。  
2. **白名单回调名**：仅允许合法 JS 标识符再包装，例如：

```text
^[A-Za-z_$][A-Za-z0-9_$]{0,63}$
```

非法则当作未传，仍返回纯 JSON。**禁止**把未校验字符串写进响应。

3. 若必须兼容上游 JSONP：先向上游要**纯 JSON**（不要带用户 callback），再由本站用白名单名包装。

平台侧已提供 `JsonpGuard`（`core/JsonpGuard.php`），本地脚本在 `bootstrap` 之后可调用，例如：

```php
$rawCb = isset($_GET['callback']) ? $_GET['callback'] : '';
$wrapped = JsonpGuard::wrapJsonIfSafe($jsonText, $rawCb);
header('Content-Type: ' . $wrapped['contentType']);
header('X-Content-Type-Options: nosniff');
echo $wrapped['body'];
```

### 自检

- [ ] 响应正文里会不会原样出现用户输入的 `callback`？  
- [ ] 是否把 `callback` 拼进了 curl 上游 URL？  
- [ ] JSONP 时是否加了 `X-Content-Type-Options: nosniff`？

## 三、响应内容：禁止泄露站内实现

公开接口返回给调用方的 JSON / 文本中，**不要**出现：

| 禁止 | 示例 |
|------|------|
| 管理后台路径 | `/admin/`、`/admin/api/list`、完整后台 URL |
| 配置与安装痕迹 | `config/database.php`、`install.lock` |
| 数据库账号密码、连接串 | 主机、库名、明文密码 |
| 平台密钥、上游密钥 | `sk_…`、后台配置的 upkey |
| 堆栈 / SQL / curl 原文 | 证书错误、PDO 异常全文 |

业务失败时建议与平台一致，只返回语义化结果，例如：

```json
{"code":0,"msg":"说明文案","errcode":11001}
```

不要在错误里附带 `api_info`、内部 ID 映射表、后台链接等。

## 四、密钥与参数

- 本站调用密钥字段常见名：`key` / `api_key` / `apikey`。转发上游前**务必剥离**，避免把平台密钥送给第三方。  
- 不要把管理员 Session、Cookie、CSRF Token 写进接口响应。  
- 需要跨域时自行评估 CORS；`Access-Control-Allow-Origin: *` 适合真正的公开数据，不适合「带登录态可读」的数据。

---

## 五、代理接口（对照，避免搞错）

| 项 | 本地接口（本目录） | 代理接口 |
|----|-------------------|----------|
| 访问方式 | `/api/你的脚本.php` 等 | **仅** `/apis/{短码}` |
| 是否支持数据库接口 ID 当路径 | 本地用 ID 只给 `ApiStats::hit(ID)` | **不支持**用 `api.id` 当 `/apis/数字` 访问 |
| 安全由谁兜底 | **作者脚本自检（本文）** | 平台网关：剥离 JSONP 参数、出站消毒、改写禁后台路径 |

把短码设成与某条记录的数字 ID 相同，只是短码碰巧长得像数字，**不是**「按 ID 访问」。网关查询条件永远是 `proxyslug`，不会 `WHERE id = ?`。
